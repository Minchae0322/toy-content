## 정답지 (원인 1줄)

테이블 charset이 utf8(3byte)라 4바이트 문자 저장 불가(Incorrect string value) — 길이가 아니라 인코딩 문제. 조치는 utf8mb4 마이그레이션.

## 근거 시그널 도달 경로

핵심: AP-1과 같은 API·같은 500이지만 **로그 지문이 다르다** — "Data too long"(길이) vs "Incorrect string value"(인코딩).
이 구별이 채점 포인트: 500이라는 결과가 아니라 예외 메시지로 원인을 갈라야 한다.
