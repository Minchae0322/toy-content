# 뱃지 설계

서비스 내 뱃지 체계 및 EXP 보상 설계 문서.
"1회성 미션"은 별도 도메인으로 만들지 않고, **뱃지 획득 시 EXP 지급** 방식으로 통합한다.

## 1. 설계 원칙

### 1.1. 기본 EXP 이코노미 (현재)

| 활동 | 기본 EXP |
|---|---|
| 피드 작성 (`FEED_CREATE`) | 30 |
| 댓글 작성 (`COMMENT_CREATE`) | 5 |
| 배틀 투표 (`BATTLE_VOTE`) | 10 |
| 배틀 가중 투표 (`BATTLE_WEIGHTED_VOTE`) | 10 |
| 배틀 아이템 추가 (`BATTLE_ITEM_ADD`) | 20 (최대 5회/배틀) |
| 배틀 예측 적중 (`BATTLE_PREDICTION_HIT`) | 100 |
| 리액션 수신 (`FEED_REACTION`) | 5 |
| PICK 한마디 (`PICK_COMMENT`) | 5 |
| HOT 발굴 (`HOT_DISCOVER`) | 50 |
| 출석 (`ATTENDANCE`) | 5 |

**STREAK_BONUS** (기존): 3일=20, 7일=50, 14일=100, 30일=200, 100일=500

### 1.2. 뱃지 EXP 공식

- **FIRST (1회성)**: 기본 활동 EXP × 2~4배 (온보딩은 후하게)
- **MILESTONE (누적)**: 기본 활동 EXP × 누적 카운트 × **15~30% 보너스 비율** (스케일 커질수록 % ↓)
- **STREAK**: `STREAK_BONUS` 와의 중복 지급을 피하기 위해 **EXP 0, 상징 트로피** (기본안)
- **QUALITY**: 희소성 반영, 동급 MILESTONE 대비 +50%
- **SEASON**: 기간 한정 가산, 런칭은 두툼하게

## 3. 스케일 검증

유저 등급별 뱃지 누적 EXP 추정:

| 등급 | 획득 예시 | 뱃지 보너스 합 |
|---|---|---|
| 라이트 | FIRST 몇 개 + `FEED_10` | ~250 EXP |
| 중간 | FIRST 대부분 + `FEED_50` + `COMMENT_50` + 뱃지 5개 | ~1,000 EXP |
| 헤비 | `FEED_100` + `BATTLE_VOTE_200` + `REACTION_RCV_500` + `HOT_MAKER` + 뱃지 20개 | ~3,500 EXP |
| 레전드 | `FEED_500` + `HOT_MAKER_10` + STREAK 풀 + `PREDICTION_HIT_50` | ~7,000 EXP |

**주요 레벨업 경로는 여전히 기본 활동 EXP** 가 담당하고, 뱃지는 **15~25% 보너스** 로 기여한다.

## 4. 미결정 / 검토 필요

1. **STREAK 뱃지 EXP**: 0 (상징) vs 50% (후하게) — 기본안은 0
2. **MILESTONE 최상위 티어** (`FEED_500`, `COMMENT_1000`, `REACTION_RCV_2000` 등) 포함 여부
3. **기존 뱃지 2개 조건 확인** — `HOT_MAKER` (HOT 1회?), `BUY_PLACE_SHARER` (구매처 10회?)
4. **뱃지 revoke 시 EXP 회수 정책** — 일반적으로 회수하지 않음
5. **SEASON 뱃지 목록** 은 본 문서에선 예시만. 실제 운영 시 시즌마다 추가/정리 필요

## 5. 구현 체크리스트 (후속)

- [ ] `Badge` 엔티티에 `rewardExp` 컬럼 추가 (기본 0)
- [ ] `ExpSource` 에 `BADGE_ACQUIRE` 추가 (`capExempt=true`)
- [ ] `ExpGrantService.grantBadgeAcquire(userId, userBadgeId, rewardExp)` 추가
- [ ] `UserBadgeService.awardBadge` / `awardBadgeIfAbsent` 에서 `rewardExp > 0` 일 때 EXP 지급
- [ ] `BadgeCode` enum 에 신규 코드 추가
- [ ] 각 뱃지 지급 트리거 핸들러 구현 (피드 작성 이벤트, 댓글 작성 이벤트 등)
- [ ] 기존 뱃지 (`HOT_MAKER`, `BUY_PLACE_SHARER`) 지급 트리거 연결
- [ ] Badge 마스터 초기 시드 데이터 삽입 스크립트
